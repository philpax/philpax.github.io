[wikitext_simplified](https://github.com/philpax/wikitext_simplified) is a Rust library that wraps `parse-wiki-text-2` with a simplified, nested representation of Wikipedia markup. It provides utilities for extracting text and manipulating nodes, so applications can work with the structure of an article without handling the parser's original output directly.
