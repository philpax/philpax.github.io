[borealis](https://github.com/philpax/borealis) was a Linux application for controlling RGB lighting on compatible Asus Aura Sync hardware, providing lighting control without using the Windows software.

<!-- more -->

After getting it working for my system, I lost interest in going any further, and [OpenRGB](https://openrgb.org/) eventually met all the same needs. Still, some people found borealis useful!
