[cardinal-rs](https://github.com/philpax/Cardinal) rewires [Cardinal](https://github.com/DISTRHO/Cardinal), the modular synthesizer platform, into a Rust library that can be embedded in other applications.

<!-- more -->

This was done to facilitate use in a spatial client for [Stardust XR](https://stardustxr.org/); unfortunately, I could not get it working to the fidelity I wanted, and I parked the project. However, I plan to revisit this with [lunette](./lunette.md); see [this issue](https://github.com/philpax/lunette/issues/78) for more details.
