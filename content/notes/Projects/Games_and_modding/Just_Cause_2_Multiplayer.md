[Just Cause 2: Multiplayer](https://store.steampowered.com/app/259080/Just_Cause_2_Multiplayer_Mod/) is a multiplayer mod for Avalanche Studios' open-world action game. My contributions covered scripting, the user interface, public relations, and supporting tooling. The project also includes work on scripts and API documentation for multiplayer servers.
