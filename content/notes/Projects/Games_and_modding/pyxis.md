[pyxis](https://github.com/ferrobrew/pyxis) is a domain-specific language for describing types and structures that already exist in a game's memory. It describes layouts, virtual tables, and functions, then generates Rust, JSON, or C++ output. This keeps reverse-engineered memory definitions separate from the code that uses them.

<!-- more -->

Supporting repositories include the [Tree-sitter grammar](https://github.com/ferrobrew/tree-sitter-pyxis) and [memory definitions](https://github.com/ferrobrew/pyxis-defs).
