[jc3vr](https://github.com/ferrobrew/jc3vr) is an unfinished Rust mod that renders Just Cause 3 in stereo for an OpenXR headset. It presents the game's interface on a separate floating panel. The project is experimental rather than a finished VR conversion.

<!-- more -->

Related tooling includes [jc3boot](https://github.com/ferrobrew/jc3boot), which starts Just Cause 3 in a state suitable for development.
