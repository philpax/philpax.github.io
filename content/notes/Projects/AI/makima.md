[makima](https://github.com/lun-4/makima) is a coding agent that I'm co-developing with [lun-4](https://l4.pm). It is a hard fork of [maki](https://maki.sh) that moves functionality from the core into Lua plugins, and revises the architecture and UI to improve scalability and performance.

<!-- more -->

In future, we hope to more [fundamentally rework the UI architecture](https://github.com/lun-4/makima/issues/159) to enable alternate interfaces (e.g. a XR coding agent in [lunette](../Graphics_and_XR/lunette.md)), and to build a [Paseo](https://paseo.sh)-style [web multiplexer](https://github.com/lun-4/makima/issues/120) to power fully-managed sandboxed development at scale.
