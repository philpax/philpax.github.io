[Disco Diffusion Studio](https://github.com/philpax/disco-diffusion) is a modernisation of the 2022 Disco Diffusion codebase. It removes everything outside of image generation, updates the code to use the latest PyTorch and `uv`, optimises generation, and adds an interactive studio interface.
