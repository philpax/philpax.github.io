tsurezure is a personal knowledge base with time as a structural dimension: wiki, diary, and lifelog in one distributed, event-sourced system. It is currently private and in active development, and takes some design inspiration from [zuihitsu](../AI/zuihitsu.md).

<!-- more -->

I have been using Obsidian for this, but:
- I want a more structured workflow that involves less copying and more automatic projection. I suspect that this could be done with plugins, but the more I have to bend Obsidian to work the way I want it, the more I think I'm using it wrong.
- I want time to be a first-class primitive in two ways: history of the knowledge base (i.e. what Git provides), and my _personal_ history (i.e. what a diary provides).

That latter consideration is the constraint that guided my design. I want every item and event to be timestamped, so that it is possible to see everything in temporal context. I want to see how it all fits together, and to potentially derive useful insights.

More to say about this once it's public, I suppose!
